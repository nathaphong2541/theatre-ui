วิธีใช้งานแพลตฟอร์ม

เรียนรู้การใช้งานเว็บไซต์เพื่อค้นหา และจัดการโปรไฟล์หรือบทละครของคุณในไม่กี่ขั้นตอน

1. เริ่มต้นใช้งาน

  • สมัครสมาชิกด้วยอีเมลของคุณ
  • ยืนยันบัญชีแล้วเข้าสู่ระบบ
  • อัปเดตโปรไฟล์ให้สมบูรณ์

2. ค้นหาสมาชิกในไดเรกทอรี่

ใช้ตัวกรองเพื่อหาโปรไฟล์ที่ตรงกับความต้องการของคุณ:

  • เลือกแผนก (Department)
  • ตำแหน่งงาน (Job Role)
  • ทักษะ (Skills)
  • สถานที่ทำงาน (Location)

3. จัดการบทละครของคุณ

  • สร้างบทละครใหม่
  • อัปโหลดไฟล์ PDF
  • เพิ่มรูปประกอบ
  • แก้ไขหรือเผยแพร่เป็นสาธารณะ

คำถามที่พบบ่อย

ต้องเสียเงินไหม?

ไม่ต้องเสียค่าบริการใด ๆ ทั้งสิ้น

จะติดต่อผู้สมัครได้อย่างไร?

ใช้ข้อมูลติดต่อที่แสดงในโปรไฟล์ของสมาชิก
